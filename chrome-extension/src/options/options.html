About this extension

This extension is part of Mathstub, a small set of tax tools for tech workers with equity compensation. Use it together with the RSU shortfall calculator, ISO/AMT calculator, and quarterly estimated tax tool to plan tax for each vest.

Privacy: data lives in chrome.storage.local on this device. No remote servers, no analytics, no cookies. Source available at the Mathstub repo.
